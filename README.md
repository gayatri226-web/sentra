# Sentra

Real-time child cyber-safety console — Omnikon National Hackathon 2026.

Sentra is a privacy-first detection engine, run by a school, that watches
for behavioral patterns that precede online harm — without ever reading
private message content.

## Structure
- backend/ — FastAPI detection engine (in progress)
- frontend/ — Next.js safety dashboard (in progress)
